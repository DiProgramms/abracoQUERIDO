# AbraçoQuerido
Este repositório está feito para algo conhecido como Projeto Amigo.

O site em questão consiste em uma plataforma onde as pessoas podem encontrar atendimento com psicólogos de forma gratuita, nascendo da visão de necessidade de alternativas para que possa abrangir o maior numero possível de pessoas.

A idealização do site como já apresentado vem do aumento exponencial e noticiado pela própria OMS do aumento gradual de casos de depressão e também de ansiedade, amplamente divulgados como o mal do século.

## Tecnologias

**Django** — backend atual (em substituição ao PHP), incluindo 
processamento de login/cadastro e gerenciamento de sessões

**PHP** — backend original do projeto, responsável pelo 
processamento de login/cadastro antes da migração

**MySQL** — armazena dados de usuários, psicólogos 
cadastrados e histórico de agendamentos

**JavaScript** — dinamicidade da interface, validações de 
formulário no frontend (login/cadastro) e desenvolvimento 
(em progresso) de um sistema de chat em tempo real entre 
usuários e psicólogos

**Bootstrap** — estilização e responsividade da interface
